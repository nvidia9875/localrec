# AudioRec

日本語に特化した、完全ローカルの文字起こしアプリ（macOS）。

音声はこの Mac の外に出ません。文字起こしは 2 つのエンジンを切り替えて使えます。

| エンジン | ローカル LLM | 特徴 |
|---|---|---|
| **Apple 音声認識**（既定） | 使わない | 実時間の約 50 倍速。真のリアルタイム表示。日本語の人名漢字に強い |
| **Whisper (MLX)** | 使う（1.6GB） | ノイズ環境に強い。録音後の取り直し向き |

`claude -p` はフィラー除去・句読点整形・要約レポート生成に使います（任意）。

---

## セットアップ

```bash
# 1. アプリをビルドして起動
make run

# 2. Whisper も使う場合（任意。Apple 音声認識だけなら不要）
make setup-sidecar
```

初回起動時に次の許可を求められます。

| 許可 | 用途 | 必須 |
|---|---|---|
| マイク | 自分の声の録音 | 必須 |
| 音声認識 | 端末内での文字起こし | 必須 |
| 画面収録とシステムオーディオ録音 | オンライン会議の相手の声 | 任意 |

Apple 音声認識の日本語モデル（数百 MB）は初回の録音時に自動でダウンロードされます。

### 権限を訊き直される場合

`scripts/build_app.sh` はキーチェーンの既存の Apple Development 証明書を自動で使います。
証明書が 1 つも無い環境では ad-hoc 署名になり、**リビルドの度に macOS が
「別のアプリ」とみなして許可を訊き直します**。その場合は署名 ID を用意してください。

```bash
CODESIGN_IDENTITY="Apple Development: ..." make build
```

## 使い方

- **⌘N**（サイドバーの「＋ 新規」）で新規作成。**いきなり録音は始まりません**。空の録音ができるので、メモを先に書いておけます
- 開いた録音のタイトル下の「録音を開始」（**⌘R**）で録音。音声がある録音では「続きを録音」になり、**前回の最後に続けて**録れます
- 録音中は「一時停止」/「再開」（**⇧⌘P**）と「停止」（**⌘R**）。一時停止中の音声は録音にも文字起こしにも入りません
- 起動すると**マイクパネル**（画面下に浮く小さなピル）が出て、ほかのアプリより手前に表示され続けます。待機中は入力デバイス名、録音中は経過時間と入力の波形が出ます。「録音」で新しい録音をすぐ始められ、一時停止・停止もパネルから押せます。↗ で本体を開きます
  - ボタン以外のところをつかんでドラッグすると動かせます。置いた位置は次回の起動でも使われます
  - 待機中はマイクを開きません（OS のマイク使用中表示は点きません）。入力レベルが出るのは録音中だけです
  - 「ウインドウ」メニュー →「マイクパネルを隠す / 表示」（**⇧⌘M**）で出し入れできます
- **Space** で再生 / 一時停止
- タイムスタンプをクリックするとその位置から再生
- サイドバーの検索は**録音を横断して発話を探します**。ヒットをクリックするとその時刻へ飛びます
- サイドバー右上のメニューでエンジンとシステム音声の録音を切り替え
- 「整形」でフィラーを除去（時刻と話者は変わりません）
- タイトルはクリックしてその場で書き換え（Enter で確定 / Esc で取り消し）。サイドバーの右クリック →「名前を変更」でも変えられます
- タイトルの下の「＋ 登場人物」で参加者の名前を登録。整形と要約で人名の表記がこれに揃います（「、」区切りでまとめて入力可）
- 「メモ」タブは自分で書くメモ。打つそばから `memo.md` に保存され、**サマリーを作るときに文字起こしと一緒に渡されます**
- 「サマリー」タブで要約レポートを生成。作り直すときは「再生成」（古い内容を消してから作り直します）

文字起こしが空（うまく認識できなかった / 音声を録っていない）でも、メモが書いてあればサマリーは作れます。

### 保存場所

`~/Documents/AudioRec/<日時>_<タイトル>/`

```
meta.json          録音の情報
audio/mic.m4a      マイク（自分）
audio/system.m4a   システム音声（相手）
audio/asr_*.wav    文字起こし用の 16kHz mono（消しても文字起こしは残る）
audio/.pending_*   続きを録音している間の一時ファイル（停止時に本体へつながって消える）
transcript.json    文字起こし（正データ）
transcript.md      人が読む用
transcript.srt     字幕
memo.md            自分で書いたメモ（サマリーの材料）
summary.md         要約レポート
```

ファイルが真実の源です。Finder からも Claude からも直接読めます。

## コマンド

```bash
make build        # .app をビルドして署名
```

### 動作確認

実機でしか確認できない部分は診断モードで確かめられます。

```bash
make selftest         # マイクから実際に録音できるか（一時停止・続きからの録音も確認）
make systemtest       # システム音声を取り込めるか
make postprocesstest  # claude -p の整形と要約
make asrtest FILE=... # 音声ファイルを文字起こし
```

## 精度

`make bench` で再現できます。合成音声 80 文 × 5 条件 = 400 ファイル。

| エンジン | CER | RTF |
|---|---|---|
| Apple 音声認識 | 3.99% | 0.019 |
| whisper-large-v3-turbo | 3.83% | 0.051 |

| カテゴリ（クリーン音源） | Apple | turbo |
|---|---|---|
| 日常・会議定型 | 0.48% | 0.24% |
| IT・開発用語 | 2.45% | 2.04% |
| **固有名詞** | **3.08%** | 8.08% |
| 数字・日付 | 2.32% | 3.09% |

固有名詞は Apple が明確に強く、ノイズ環境は Whisper が強い、という住み分けです。
既定を Apple にしている理由と、日本語特化モデル（kotoba-whisper）を採用しなかった
経緯は `PLAN.md` を参照してください。

### 用語辞書

`~/Documents/AudioRec/glossary.json` に置きます。

```json
{
  "terms": ["鴻上", "プルリクエスト"],
  "corrections": { "神神": "鴻上" }
}
```

`corrections` は認識後の置換で、**これが最も確実に効きます**。
`terms` は Whisper の `initial_prompt` に載りますが、Apple 側の
`contextualStrings` は実測では効果がありませんでした（`PLAN.md` 参照）。
